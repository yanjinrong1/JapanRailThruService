# Data and third-party sources

- Mini Tokyo 3D: https://github.com/nagix/mini-tokyo-3d — MIT, Akihiko Kusanagi. See `dist/DATA-LICENSE.txt`.
- MLIT National Land Numerical Information N02 Railway Data, 2024: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html
- MLIT terms: https://nlftp.mlit.go.jp/ksj/other/yakkan.html
- MLIT JSON processing: https://github.com/antfu/mlit-json
- OpenFreeMap: https://openfreemap.org/ — map data from OpenStreetMap / OpenMapTiles.
- OSM copyright: https://www.openstreetmap.org/copyright

Railway snapshots are filtered and processed for this map. These are geographic/stopping-pattern references, not a live timetable. Operator logos remain the marks of their respective operators; Wikimedia file URLs and official timetable sources are retained in the app configuration and information dialog.

Leaflet licensing is included in the vendored source header. MapLibre / MapLibre GL Leaflet licenses are included in `dist/vendor/`.
